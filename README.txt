KÉT OPCIÓ • PARTY

Ez egy egyszerű, mobilbarát online partyjáték 4–5 főre.

Játékmenet:
- A lobby létrehozója megosztja a 4 karakteres kódot.
- 4–5 játékos csatlakozik.
- A host elindítja a játékot.
- Minden körben a szerver véletlenszerűen választ egy kérdésírót.
- A kérdésíró beír két opciót.
- A többiek külön telefonról szavaznak.
- Az eredmény után a host indítja a következő kört.
- Ugyanaz a játékos nem lesz egymás utáni két körben kérdésíró, ha van másik játékos.

Futtatás:
1. Telepíts Node.js 18 vagy újabb verziót.
2. Csomagold ki a ZIP-et.
3. A mappában futtasd: npm install
4. Indítás: npm start
5. Böngészőben: http://localhost:3000

FONTOS:
Ahhoz, hogy a barátaid külön telefonról, interneten keresztül csatlakozzanak,
a projektet egy publikus Node.js tárhelyre kell telepíteni (pl. Render vagy Railway).
A localhost cím csak a saját eszközödön érhető el. A projekt forráskód,
nem egy már publikusan hosztolt weboldal.
